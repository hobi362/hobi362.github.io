Worked in the Systems and Analysis Group on terrain-following flight trajectories —
essentially, how an aircraft should fly to hug terrain as closely as possible for a given
radar-testing scenario. I developed and integrated a MATLAB algorithm for this directly
into the group's existing radar testing software, which meant learning to write code that
had to play nicely with a much larger existing codebase rather than starting clean.

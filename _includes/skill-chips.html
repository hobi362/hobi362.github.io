{%- comment -%} Skills and Stack rows for a project / research / experience page. Both rows come from _data/skills.yml, the single index: entries with kind "skill" are capabilities, entries with kind "stack" are the specific things used. Each entry exists once, so the two rows can never show the same thing twice, and every chip links to that entry on /skills/. A page with many skills can cap the Skills row from its own front matter: skills_show: ["surgical-robotics", "medical-devices"] Those chips render in that order and the rest collapse into a "+N more" link. The index still credits the page under every entry that lists it. {%- endcomment -%} {%- assign total = 0 -%} {%- for s in site.data.skills -%} {%- if s.kind == "skill" and s.pages contains page.url -%}{%- assign total = total | plus: 1 -%}{%- endif -%} {%- endfor -%} {%- assign shown = 0 -%} {%- capture skill_chips -%} {%- if page.skills_show -%} {%- for id in page.skills_show -%} {%- for s in site.data.skills -%} {%- if s.id == id and s.kind == "skill" and s.pages contains page.url -%} {%- assign shown = shown | plus: 1 -%} {{ s.short | default: s.name }} {%- endif -%} {%- endfor -%} {%- endfor -%} {%- else -%} {%- for s in site.data.skills -%} {%- if s.kind == "skill" and s.pages contains page.url -%} {%- assign shown = shown | plus: 1 -%} {{ s.short | default: s.name }} {%- endif -%} {%- endfor -%} {%- endif -%} {%- endcapture -%} {%- capture stack_chips -%} {%- for s in site.data.skills -%} {%- if s.kind == "stack" and s.pages contains page.url -%} {{ s.short | default: s.name }} {%- endif -%} {%- endfor -%} {%- endcapture -%} {%- if skill_chips != "" %}
